# Happy Birthday Daniel

Interactive narrative birthday gift — five stages of story + games.

## Run locally

```bash
# needs Node 20+ (or: nvm use 22)
npm install
npm run dev
```

Open the Local URL Vite prints (usually http://localhost:5173/).

## Replace placeholder art

Drop real images over these files (keep the same names, or update `src/data/story.ts`):

- `public/characters/me.svg`
- `public/characters/daniel.svg`
- `public/characters/bull.svg`

PNG/JPG also works if you change the paths in `src/data/story.ts`.
